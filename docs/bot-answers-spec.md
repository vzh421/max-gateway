# Задание для сессии бота: ответы должникам (S4)

Основание — анализ реальной переписки `docs/debtor-needs.md` (90 чатов, 4601 сообщение). Этот
документ — выжимка для реализации в боте. Правила проекта (CLAUDE.md) имеют приоритет.

## Жёсткие рамки

1. **Бот отвечает сам только фиксированными текстами, утверждёнными управляющим, с подстановкой
   данных дела.** Никаких сгенерированных формулировок с правовой оценкой. До утверждения текст
   помечен `[НЕ УТВЕРЖДЕНО]` и в чат не уходит.
2. **Юридические вопросы — только черновик на одобрение управляющему** (CLAUDE.md, S4), в чат
   ничего автоматически не отправляется.
3. **Сведения по делу — только привязанному пользователю** (привязка по токену шлюза,
   `docs/bot-integration.md`). В переписке часто пишут родственники — им данных дела не выдавать.
4. Бот сообщает факты («заседание назначено на …») и не прогнозирует решение суда.

## Единица обработки — обращение, а не сообщение

63% сообщений должников — реплики внутри диалога («Здравствуйте», «Хорошо», «???»). Нужно:
- собирать сообщения пользователя за короткое окно (порог выбрать и настроить) в одно обращение;
- определять тему по обращению целиком и отвечать один раз;
- на приветствия и подтверждения без вопроса отдельно не отвечать.

## Что нужно от ai4au (для класса А)

Высокий приоритет: процедура и дата окончания; ближайшее заседание и переносы; последний акт;
статус дела; требование о финансировании и реквизиты; **срок действия последнего согласия на
снятие** — этого поля, по анализу, нет в учёте, а именно оно даёт больше всего повторных
обращений. Средний: платежи, иждивенцы, регион, реестр, дата принятия заявления, документы.
Отдельно — справочник прожиточного минимума по регионам (обновлять ежегодно).

API ai4au: см. CLAUDE.md репозитория max-gateway, раздел «Интеграция с ai4au». Доступ — только
чтение по сервисному токену.

## Метрики для контроля после запуска

- доля обращений, закрытых без управляющего (ожидание по анализу — около 25%);
- время до первого ответа (сейчас 17% ответов управляющего — через 4 дня и позже);
- доля чатов, где последнее слово осталось за должником без ответа (сейчас 66 из 90).
